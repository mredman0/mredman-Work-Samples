# Mark Redman Work Samples

Production source excerpts from some of my projects. Each folder shows a selected handful of systems which I designed and wrote without AI.

## [Idle Tic Tac Toe](Idle%20Tic%20Tac%20Toe/)

An idle game whose boards play tic-tac-toe to earn Gum. The sample covers the self-running board (including a high-speed analytic mode), shared upgrade-purchase math, a typed bonus bus, skill-tree effects that write into that bus, and the `coefficient × 10^exponent` number type currencies sit on.

## [ChromaSphere](Chromasphere/)

**ChromaSphere: 3D Line Puzzle**, shipped on Android and iOS. Players connect matching colored nodes on a sphere without crossing paths. The sample covers spherical grid and path-drawing gameplay, a seeded daily-puzzle generator plus the client that fetches it, Unity IAP (ad-free, hints, daily packs), and LevelPlay ads wired to a hint wallet.
